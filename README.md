# DevDocks

DevDocks is a browser-based coding sandbox for creating, editing, running, and previewing projects without local project setup. It gives developers an IDE-style workspace with file management, live preview, terminal-like commands, project persistence, npm package management, extension controls, and a recycle bin for safer recovery.

## Features

- Create and manage multiple coding projects from a dashboard.
- Edit project files in a browser IDE workspace.
- Preview React, JavaScript, TypeScript, CSS, and HTML changes live.
- Install and remove virtual npm packages from the workspace.
- Use terminal-style commands for common project actions.
- Save project state locally in the browser.
- Restore deleted projects or files from the recycle bin.
- Manage profile, extensions, packages, files, preview, and terminal panels.

## Tech Stack

- React
- TypeScript
- Vite
- Zustand
- Monaco Editor
- Tailwind CSS

## Getting Started

```bash
cd devdocks
npm install
npm run dev
```

The app runs on `http://localhost:3000` by default.

## Available Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
